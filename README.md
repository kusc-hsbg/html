# PPOLPPOL WORLD · Craft & Explore

첨부된 `머리커스텀.zip`의 12개 머리 스타일을 사용한 로컬 2D 월드 프로토타입입니다.

## 실행
- 가장 간단한 방법: `standalone.html` 단일 파일을 더블클릭합니다. (배포용 파일명: `ppolppol_world_craft_v5.html`)
- 프로젝트 버전: 이 폴더의 `index.html`을 열거나 `start_server.bat`을 실행한 뒤 브라우저에서 안내 주소로 접속합니다.

## 조작
- 이동: WASD / 방향키
- 상호작용: E 또는 C
- 춤: Z 또는 V
- 낚시: F 또는 X
- 공격: J
- 핫바 선택: 1~6

## 주요 콘텐츠
- 나무 벌목 → 나무 획득 → 나무 6개로 나무검 제작
- 바위 채광 → 돌 획득 → 돌 곡괭이 / 돌 도끼 업그레이드
- 베리 채집과 가공
- 낚시 타이밍 미니게임
- 슬라임 전투와 드롭 보상
- 모닥불 키트 제작 및 월드 설치
- 일일 목표, 경험치, 레벨, 도감, 인벤토리
- 로컬 저장
- 같은 브라우저에서 여러 탭을 열면 위치와 캐릭터가 서로 보이는 로컬 룸 시뮬레이션
- 별도의 채팅 UI는 포함하지 않음

## 캐릭터 방향 처리
- 아래 방향: 정면 원본
- 왼쪽 방향: 첨부된 왼쪽 옆모습 원본
- 오른쪽 방향: 왼쪽 옆모습을 수평 반전
- 위 방향: 정면 실루엣을 머리카락 대표 색상으로 채운 뒤 뒷머리 느낌의 디테일을 추가한 이미지
- 몸: 캔버스에서 방향과 행동에 따라 실시간으로 그리며 걷기, 춤, 도구 사용 모션에 대응

## 파일 구성
- `index.html` UI 구조
- `style.css` 전체 UI/반응형 디자인
- `game.js` 월드, 캐릭터, 제작, 채집, 전투, 낚시, 저장 로직
- `assets/heads/front` 정면 머리
- `assets/heads/left` 왼쪽 옆모습 머리
- `assets/heads/back` 자동 생성 뒷모습 머리


## v5 캐릭터·제작 개선
- 12종 머리의 실제 투명 영역을 기준으로 정면/옆/후면 크기를 자동 보정해 방향을 바꿔도 머리 크기가 튀지 않습니다.
- 긴 머리(h02, h05, h06, h10, h12)는 머리 전체를 뒤에 두고 몸을 위에 올린 뒤 얼굴/앞머리만 자연스럽게 복원하는 레이어 방식으로 변경했습니다.
- 몸을 둥근 맨투맨, 작은 손, 짧은 다리, 말랑한 신발 형태의 치비 비율로 다시 그렸습니다.
- 옆모습은 제공된 왼쪽 원본을 사용하며 오른쪽은 동일한 크기와 기준점으로 수평 반전합니다.
- 나무검 제작은 나무 6개가 되는 즉시 제작 버튼이 활성화되며, 제작 패널을 열어 둔 상태에서도 실시간으로 갱신됩니다.
- 재료 부족 메시지, 제작 가능 알림, 나무검 완성 이펙트, 자동 핫바 선택, 저장까지 보강했습니다.
